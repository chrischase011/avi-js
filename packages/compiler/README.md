# @avijs/compiler

Optional build-time checks and manifests for Avi.js apps (avi-compile).

A building block: apps do not install it directly, since the `avi` CLI (`@avijs/cli`) includes it.
Its own exports may change in a 1.x minor release; see [Stability and
versions](https://github.com/chrischase011/avi-js/blob/main/docs/tutorial/17-stability.md).

Part of [Avi.js](https://github.com/chrischase011/avi-js), a TypeScript framework for Node.js with
modules, controllers and dependency injection, without `reflect-metadata`. See the
[tutorial](https://github.com/chrischase011/avi-js/blob/main/docs/tutorial/README.md) to get started.

Requires Node.js 22.12 or newer. MIT licensed.
